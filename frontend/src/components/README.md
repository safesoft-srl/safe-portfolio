# Components

This folder contains reusable React components that are shared across the application (e.g., buttons, inputs, modals).

## Naming Convention

Use **PascalCase** for React components and their files.

- Examples: `PrimaryButton.tsx`, `UserProfileCard.tsx`

_Note: Component libraries (like shadcn/ui inside `ui/`) might use **kebab-case** (e.g., `button.tsx`) which is acceptable for those specific auto-generated implementations._
